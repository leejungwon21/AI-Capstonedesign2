# 사례 ⑥ — 교육자료 수정

사용자가 복사한 DM 5개를 검토했다. 자동 추출이나 ML 예측이 아니다. source.json은 원문, scenario.json은 실험 설정이며 이 검토 문서는 추출 모델 입력에서 제외한다.

## 실험 설정
월요일 오전 대화 이후 13시에 원이정이 갑자기 부재하고 복귀 시점은 미상이라고 가정한다. 이는 앞서 정한 가상 설정이며 Slack에 표시된 15:48~15:49는 실제 게시 시각으로 별도 보관한다. 날짜와 정확한 제출·검토 시각은 알 수 없다.

| 정보 | 대화로 확인되는 내용 | 근거 |
|---|---|---|
| 초안 | 공유폴더 업로드, 목차·본문 완료 보고 | case_06_M001 |
| 남은 작업 | 화면 캡처 두 장 교체. 대화 당시 미실행 | case_06_M001, case_06_M005 |
| 제출 마감 | 다음 주 금요일, 시각 미상 | case_06_M001 |
| 검토 예정 | 다음 주 수요일, 검토자·시각 미상 | case_06_M003 |
| 후속 업무 | 이번 주 자료를 기다리는 업무가 없다는 원이정의 보고 | case_06_M003 |
| 문서 | 캡처 위치가 문서에 있다고 보고 | case_06_M002, case_06_M005 |
| 대체 후보 | 홍길동은 파일 확인 및 과거 수정 경험을 보고 | case_06_M002, case_06_M004 |

## 인계 시 확인할 사항
- 최신 파일과 문서를 확인하고 화면 두 장의 교체 여부를 확인한다.
- 홍길동의 현재 작업 가능 시간과 필요한 화면 접근·편집 권한을 확인한다. 과거 경험은 현재 수락이나 권한을 보장하지 않는다.
- 다음 주 수요일 검토 전까지 작업할 담당자를 정한다. 발언에 작업→검토 순서가 명시되지는 않았으므로 이는 제안이다.

## 판단의 한계
다른 임박한 마감 사례보다 즉시 대응 압박이 낮다는 검토 의견은 가능하지만, 업무를 방치해도 된다는 뜻은 아니다. 실제 파일·문서와 권한을 검증하지 않았다. 후속 업무가 전혀 없다고 일반화하지 않는다. 우선순위 라벨은 독립 평가 전이므로 미정이다.
