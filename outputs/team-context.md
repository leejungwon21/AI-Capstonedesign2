# 보증팀 업무 분장 — 사용자 제공 정보

회사 공식 조직도 원본이 아니라 사용자가 설명한 과거 팀 구성이다. 직접 보고 관계와 직급을 추가 추론하지 않는다.

| 이름 | 확인된 직책 | 주요 업무 |
|---|---|---|
| 이주용 | 팀장 | 세부 업무·승인 권한 미상 |
| 이혜정 | 매니저 | 마감 관련 |
| 이재영 | 매니저 | 마감 debit 처리, 감사 관련 |
| 이준화 | 미상 | 데이터 분석, 에러로그 관리 |
| 이형주 | 미상 | 딜러 소통 게시판 답변, 쿠폰 마감, 패키지 등록 |
| 송영종 | 미상 | 딜러 성과급 조정 관련 DHC 프로젝트. 사용자 제공 recap 메일의 분석 요청자 |
| 원이정 | 인턴 | 기존 보증마감·SAP 사례의 실행 업무 |

## 확인된 대체 규칙
원이정 부재 시 사례 ①의 세금계산서 취합·미회신 딜러사 후속 확인을 이혜정이 대신 맡는다. 사용자가 설명한 팀 역할에 근거한다. 모든 인턴 업무나 다른 사람의 부재에 자동 적용하지 않는다. 다른 대체 규칙은 미상이다.

## 추가 자료
사용자가 이후 DHC recap 메일 본문을 채팅에 제공했다. 원이정·이형주 공동 분석 요청과 시나리오 C 제외 등의 범위를 `dhc-project-07/context.md`에 정리했다. 이는 네 번째 시트를 직접 읽은 결과가 아니다. 공동 작업 관계를 자동 대체 규정으로 해석하지 않는다.

사용자가 송영종 프로젝트 참고 자료로 지정한 `intern정리.xlsx`의 네 번째 시트는 읽기 권한 요청 후에도 운영체제 접근 거부로 열리지 않았다. 시트 이름·내용·업무 절차는 아직 확인하지 못했다. 원본 파일은 수정하지 않았다.

## 사례와의 관계
기존 사례 ①·②는 사용자 업무 경험의 재구성이다. ③~⑥의 홍길동은 가상 인물이며 이 팀의 실제 인물로 자동 치환하지 않는다. 신규 팀 기반 사례에는 확인된 업무 분장과 개별 대체 규칙을 사용한다.
