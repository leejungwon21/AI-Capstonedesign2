# 사례 ③ — 주간 정산표

사용자가 DM을 복사해 제공한 5개 메시지를 검토했다. 자동 추출·ML 예측 결과가 아니다. source.json은 원문 자료, scenario.json은 별도 실험 설정이다. 이 검토 문서는 추출 모델 입력에서 제외한다.

실험 설정: 화요일 오전 대화 이후 13시에 원이정이 갑자기 부재. 마감은 15시이므로 2시간 남음. 실제 게시 시각 15:30~15:31을 업무 시각으로 쓰지 않는다.

| 업무/정보 | 확인된 내용 | 근거 ID |
|---|---|---|
| 금액 대사 | 원이정이 완료했다고 보고 | case_03_M003 |
| 파일 저장 | 공유폴더의 주간정산_최종.xlsx로 저장했다고 보고 | case_03_M003 |
| 파일 업로드 | 대화 당시 미실행, 이후 수행 계획만 있음 | case_03_M003, case_03_M005 |
| 완료 메일 | 대화 당시 미발송, 이후 완료 기록 없음 | case_03_M003 |
| 홍길동의 경험 | 지난주 업로드·완료 메일 수행 보고 | case_03_M002 |
| 파일·문서 | 홍길동의 열람·합계 확인 보고와 지난주 문서 언급 | case_03_M004 |

인계 시 확인할 일: 부재 시점까지 업로드·메일 발송이 실제로 됐는지 확인하고, 미처리라면 홍길동에게 현재 처리 가능 여부와 업로드 권한을 확인한다.

홍길동은 대체 후보이지 확정된 대체 담당자가 아니다. 지난주 완료 사실은 이번 주 업무의 완료가 아니다. 파일·문서 원본이 없어 존재·내용·권한을 직접 검증하지 않았다. 실제 공유 경로와 회계팀 수신 주소는 미상이다.

우선순위 정답은 아직 독립 검토하지 않았다. 업무 → 담당자 연결과 대체 후보의 과거 경험을 표현하는 개발 사례로 사용한다.
