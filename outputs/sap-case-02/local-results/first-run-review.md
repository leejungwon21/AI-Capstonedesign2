# 로컬 모델 첫 추출 검토

모델: qwen3:4b-instruct. 입력: SAP S001~S006와 일반 추출 지시문. 정답표는 입력하지 않았다. 검토 대상: 20260920T075854554733Z-validated.json.

실제 로컬 추론과 파일 저장에 성공했다. 파일명의 validated는 JSON 형식과 출처 ID 검사 통과만 의미한다. 의미 정확성 검토 결과는 불합격이며 인수인계 데이터에 자동 반영하지 않는다.

| 항목 | 결과 |
|---|---|
| 승인 상태 갱신 | S004 승인 완료 보고를 반영함 |
| 수요일 마감의 불확실성 | confirmed=false로 표현함 |
| MIGO·마충렬 제출 | 독립된 남은 업무로 추출하지 못함. unknowns에만 언급 |
| 날짜 | 원문에 없는 2025-04-01을 생성함 |
| 승인 완료 시각 | 원문의 13:30을 15:30으로 잘못 표시함 |
| 담당·수신자 | 승인자들을 하나의 담당 문자열로 합치고 수신자를 이혜정으로 묶어 실행 담당·승인자·제출 수신자를 구분하지 못함 |
| 순서 | S005의 MIGO 후 제출 순서를 관계로 추출하지 못함 |

한 사례의 개발 검토이며 정확도 수치로 일반화하지 않는다. 다음 개선은 업무 추출과 상태 판정을 나누고, 날짜를 원문의 상대 시간 표현으로 제한하는 것이다. 개선된 지시문은 정답의 업무명이나 특정 메시지 정답을 직접 삽입하지 않고 다른 사례에서도 검증해야 한다.
