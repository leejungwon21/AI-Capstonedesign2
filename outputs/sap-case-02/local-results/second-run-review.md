| 항목 | 첫 실행 | 두 번째 실행 |
|---|---|---|
| MIGO·회계 제출 | 업무 목록에서 누락 | 결합된 업무 하나로 탐지, 계획·완료 미확인으로 표시 |

상세 오류: 정상환 대상 메일의 수신자를 대화 상대 원이정으로 오인. 클립 전달 지시의 수행자를 지시자 이혜정으로 오인. 이는 대화 발신자·수신자와 실제 업무 실행자·산출물 수신자를 구분하지 못한 문제다.

한계: v2는 마감과 의존 관계를 아직 출력하지 않으므로 v1보다 전체 기능이 우수하다고 결론내리지 않는다. 일곱 항목을 뽑았다고 일곱 개의 올바른 업무를 찾았다는 뜻도 아니다. 형식·인용 검사를 통과해도 의미 검토는 불합격이다.

다음 개선 대상: 행동 단위 분리, 동일 업무 상태 이력 통합, 대화 참여자와 업무 역할의 구분. 새 지시문은 SAP의 특정 이름·업무 정답을 하드코딩하지 않고 다른 사례에서 함께 점검해야 한다. 이번 결과는 기존 인계 데이터에 자동 합치지 않았다.
